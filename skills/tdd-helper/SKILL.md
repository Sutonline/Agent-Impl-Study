# TDD Helper Skill

When building or fixing a feature with TDD:
1. Write or update the unit test file first.
2. Run the test via `bash` to confirm it fails (RED).
3. Write the minimal implementation code to pass the test (GREEN).
4. Re-run the test to confirm it passes.
